# Transporter

Transporter copies a file or directory tree from one machine to another with
no setup. It is encrypted, integrity-checked, and resumes after network
failures. The receiver prints a one-time code; the sender uses it.

This project is under construction; see [docs/requirements.md](docs/requirements.md)
and [docs/DECISIONS.md](docs/DECISIONS.md).
